# Movie Information Portal

A simple frontend academic project built using HTML5, CSS3, JavaScript, DOM, jQuery and Bootstrap 5.

## Pages
- `index.html` — Home page
- `movies.html` — Movie listing with basic search and genre filter
- `movie-details.html` — Information about a selected movie
- `favorites.html` — Saved watchlist
- `reviews.html` — Submit and view reviews
- `contact.html` — Contact form

## How to run
1. Extract the ZIP file.
2. Open this folder in Visual Studio Code.
3. Run `index.html` with Live Server, or open it in a browser.
4. An internet connection is recommended for Bootstrap, jQuery, fonts and movie posters.

## Notes
- Movie information is stored in `js/movies.js`.
- The watchlist and reviews use browser LocalStorage.
- This is a frontend-only student project; there is no server or database.
